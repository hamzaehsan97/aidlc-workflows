Read `.company-aidlc/knowledge/company-saas-product-discovery.md` from the target repository
root. If the snapshot is not installed, read the equivalent
`plugins/company-saas/knowledge/aidlc-shared/company-saas-product-discovery.md` from this
extension checkout. If neither is available, report the missing guide before using
company-specific assumptions.

Read existing evidence first. Separate observed results from assumptions; use the installed discovery-brief template only when no equivalent exists. Recommend the smallest next experiment or investment and name its decision owner. Do not fabricate interviews or imply authorization to contact customers.

Templates are in `.company-aidlc/templates/` after bootstrap or `company/templates/`
in the source checkout. Keep sensitive evidence in the owning private repository.
